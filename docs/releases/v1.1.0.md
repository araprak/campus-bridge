## Earlier change log

[Version history](https://campusbridgeguide.com/releases) now includes an Earlier change log section with all ten historical groups, v0.1–v2.3, from the supplied CampusBridge_Change_Log.docx. Each label opens its corresponding GitHub document directly. The [historical index](../history/README.md) provides all 113 numbered entries across those documents, status definitions, and the original verification worksheet and source trail.

Entry IDs, descriptions, recorded statuses, and date wording are preserved. Counts on the website show the entries and statuses within each group. The source's verification fields were blank, so the archive does not claim that requested, proposed, or reported items were independently verified or released on those dates.

Historical labels are separate from the three-part releases shown above them. In particular, historical v1.0 is not release v1.0.0. This update publishes the historical record; it does not implement its pending features. The approved About page is unchanged.
