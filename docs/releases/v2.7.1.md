# CampusBridge v2.7.1

Release date: 2026-10-28

## Shared: Accurate account-save confirmation

The arrival planner validates and normalizes a saved route. That normalization could change object field order and make a successful save show a misleading message about newer unsaved edits. The save now compares the draft at the start and end of the request, so a successful save reports accurately. Actual edits made while a save is pending are still kept in the tab.

The Group A, Group B and shared features from v2.7.0 retain their assigned hosts. See the [verification record](../group-sites/verification-v2.7.md) for automated and live checks and the remaining physical-device, venue and future January limits.
