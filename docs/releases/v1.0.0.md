# CampusBridge v1.0.0

Release date: 2026-10-24

Meet the team and follow product updates.

## About the team

The About page now shows the CampusBridge team’s photos and names. The existing explanation of how CampusBridge works remains available on the separate [How it works page](https://campusbridgeguide.com/how-it-works).

## Linked version history

The new [Version history page](https://campusbridgeguide.com/releases) lists documented CampusBridge releases, newest first. Select a version number to open its full release document directly on GitHub. The website footer also links to version history.

## Release notes for every feature

Each future feature update will include a new version and release notes describing the user-facing change. Fixes will receive patch versions, new features minor versions, and incompatible changes major versions. Checks keep the website’s release list, release documents, and application version aligned.

## Versioned release history begins here

v1.0.0 is the first release in this versioned history. It records the changes listed above; it does not claim that all existing CampusBridge functionality was first launched on this date. Earlier labels v0.1–v2.3 grouped requests and are not shipped release versions.
