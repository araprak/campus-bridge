# CampusBridge v2.8.0

Release date: 2026-10-28

## Group B: Website language selector

Group B now has one website language selector above the page content, available before and after sign-in. Its English labels appear in alphabetical order: Arabic, Cantonese, English, French, German, Hindi, Italian, Japanese, Kannada, Korean, Malayalam, Mandarin, Portuguese, Spanish, Tamil, Telugu and Urdu. Native names make the options easier to recognize. Malayalam and Portuguese use their standard spellings. Mandarin uses Simplified Chinese; Cantonese uses Traditional Chinese and Hong Kong wording.

The selector translates 260 core interface phrases across Group B’s navigation, authentication, landing previews, budget and reminder controls, statuses and source-report controls. Translations are bundled locally and loaded on demand. No account details, page content or input values are sent to a translation service. The choice is remembered for up to one year in a cookie on the Group B origin only. Arabic and Urdu use right-to-left layout; returning to English restores the original interface.

Entered values, saved reminder titles, scenario names and report messages remain unchanged. Official-source content, glossary definitions, legal text, historical release documents and text without a bundled translation retain their original language. The selector states this boundary; these are interface translations, not professional translations of official immigration, medical or legal instructions. External source pages remain under their publisher’s language controls. The earlier separate Hindi/Korean term pilot has been replaced by this single website selector.

The feature appears only on the exact Group B host. Group A and the main site retain English and ignore Group B’s preference. Both remain on the shared release timeline; this release does not merge group features.
