# CampusBridge v2.5.1

Release date: 2026-10-25

## Map failure and pause resilience

A delayed resize callback could run after Google Maps discarded its container during an authorization failure or after the map was closed. The callback now ignores removed or replaced containers and stops after cleanup. Pending camera work also waits for a connected container.

The housing list, filters, directions and other group tools remain available when the map is paused or unavailable. This patch does not change Google key permissions, API configuration or billing. Students may still see the unavailable-map panel if Google rejects the current site address.

Validation reproduced the local rejected-referrer, fallback and close sequence. The original uncaught camera/resize error did not recur and the arrival tool remained usable. Provider errors handled by the existing map error boundary can still be logged. This is failure-path verification, not proof that Google accepts the Group A production hostname; that remains part of the signed-in production check.
